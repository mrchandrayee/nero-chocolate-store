A premium **bean-to-bar chocolate store** UI with editorial design, product showcase, add-to-bag interaction, and smooth animations. Built with pure HTML, CSS & JavaScript.

---

## ✨ Features

- 🍫 **4 chocolate products** — Sea Salt, Orange, Noir 85%, Origin 72%
- 🛍️ **Add to Bag** — live bag counter with toast notification
- 🎨 **Editorial design** — Playfair Display + DM Sans typography
- 🌀 **Floating cocoa beans** — CSS keyframe animation
- 📦 **Product switcher** — thumbnail nav with smooth transitions
- 💰 **INR pricing** — Indian rupee formatting
- 📱 **Fully responsive** — mobile-first layout
